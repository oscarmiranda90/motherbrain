# Assets

`motherbrain.png` — the project mark: a dithered monochrome brain with a single
central eye, in phosphor green.

Deliberately abstract. It reads as "brain with an eye" without reproducing any
particular execution of that idea: no detailed convolutions, no mechanical
tubing, and a one-colour CRT palette rather than full colour. The green is also
the point — it is what a terminal looks like, which is where this tool lives.
